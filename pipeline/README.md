# Состояние фич в конвейере агентов

Один файл `<feature>.json` на фичу. Его создаёт и ведёт `/pipeline` (`.claude/skills/pipeline/SKILL.md`), агенты дописывают в него свои результаты. Формат и переходы — в описании навыка.

Человек правит здесь только одно: решение в воротах `human_decision`, если удобнее записать его в файл, чем сказать в чате.
