# Инструкция для ректора и декана

Руководство работает с компьютера: меню слева. Декан (завкафедрой) видит и меняет только своё отделение; семестры, аудитории, звонки и админ-аккаунты — только у ректора.
Названия даны как в интерфейсе на кыргызском, в скобках — по-русски. Вход, пароль, язык — как в `teacher.md`.

## Главная страница и отчёт
<!-- feature: dashboard · version: 0.0.0 -->
Когда нужно: каждый день — увидеть, как идёт учёба.
1. «Башкы бет» (Главная) открывается сразу после входа.
2. Вверху — мугалимдер, дайындоолор, жумасына сабак, камсыздоо (учителя, назначения, уроки в неделю, покрытие).
3. «Мугалимдердин жүктөмү» — нагрузка учителей; «Мугалими дайындалбаган сабактар» — предметы без учителя.
4. «Мониторинг»: период «Күн / Жума / Ай / Жыл» (день, неделя, месяц, год) — запланировано, проведено, пропущено; «Эң көп сабак калтыргандар» — кто больше всех пропустил.
5. «Отчетту жүктөп алуу» (Скачать отчёт) — файл Excel за выбранный период (можно выбрать группу).

## Проверить, проводят ли учителя уроки
<!-- feature: monitoring · version: 0.0.0 -->
1. «Мониторинг» → период.
2. По каждому учителю: «Пландалган» (запланировано), «Өткөрүлгөн» (проведено), «Калтырылган» (пропущено), «Кечиккен» (опоздания), «Көрсөткүч».
3. Нажмите на имя учителя — его уроки по дням: предмет, группа, статус, время прихода и окончания.

Урок считается пропущенным, если учитель не открыл его в журнале в своё время.

## Отметить пропуск по уважительной причине
<!-- feature: excuses · version: 0.0.0 -->
Когда нужно: ученик болеет, уехал по семейным делам — до или после уроков.
1. «Себептүү жоктуктар» (Пропуски по уважительной причине) → «Кошуу» (Добавить).
2. Студент, «Кайсы күндөн» и «Кайсы күнгө чейин» (с какого по какой день), «Себеби» (причина) → «Сактоо» → «Ооба».
3. В эти дни ученик в журнале учителя сам отмечен «Себеби бар», учитель не может это изменить.

## Студенты
<!-- feature: students · version: 0.0.0 -->
1. «Студенттер» (Студенты): поиск по имени, карандаш — изменить, корзина — удалить (если есть отметки, приложение предупредит).
2. Нажмите на имя — история занятий по предметам (проведено, пропущено, экзамены, средний балл) и общие комментарии учителей.
3. «Кошуу» → обязательны «Аты-жөнү» (ФИО) и «Топ» (группа); телефон родителей, дата рождения, адрес, фото — по желанию → «Сактоо» → «Ооба». Ученик сразу появится в журнале учителя.

## Настройка медресе — по порядку
Справочники заполняются один раз в начале года, дальше только меняются. Порядок важен: каждый следующий шаг выбирает из предыдущих.
Везде одинаково: «Кошуу» (Добавить) → поля со звёздочкой обязательны → «Сактоо» → «Ооба»; в таблице карандаш — изменить, корзина — удалить
(удалить нельзя, пока на запись что-то ссылается — приложение скажет, что именно).

### 9. Расписание
<!-- feature: schedule-edit · version: 0.0.0 -->
«Сабак жадыбалы»: строки — пары, столбцы — дни. «+ кошуу» в свободной ячейке → назначение и аудитория → «Кошуу».
Если учитель, группа или аудитория в это время заняты — приложение не даст поставить и объяснит почему.
Нажмите на урок: «Жылдыруу» — перенести, «Өчүрүү» — удалить (если по уроку уже есть отметки, приложение предупредит).
