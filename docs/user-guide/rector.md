# Инструкция для ректора и декана

Руководство работает с компьютера: меню слева. Декан (завкафедрой) видит и меняет только своё отделение; семестры, аудитории, звонки и админ-аккаунты — только у ректора.
Названия даны как в интерфейсе на кыргызском, в скобках — по-русски. Вход, пароль, язык — как в `teacher.md`.

## Главная страница и отчёт
<!-- feature: dashboard · version: 1.0.1 -->
Когда нужно: каждый день — увидеть, как идёт учёба.
1. «Башкы бет» (Главная) открывается сразу после входа.
2. Вверху — мугалимдер, дайындоолор, жумасына сабак, камсыздоо (учителя, назначения, уроки в неделю, покрытие).
3. «Мугалимдердин жүктөмү» — нагрузка учителей; «Мугалими дайындалбаган сабактар» — предметы без учителя.
4. «Мониторинг»: период «Күн / Жума / Ай / Жыл» (день, неделя, месяц, год) — запланировано, проведено, пропущено; «Эң көп сабак калтыргандар» — кто больше всех пропустил. «Жума» — с понедельника по сегодня, «Ай» — с 1-го числа месяца по сегодня, «Жыл» — с 1 января по сегодня.
5. «Отчетту жүктөп алуу» (Скачать отчёт) — файл Excel за выбранный период (можно выбрать группу).

## Проверить, проводят ли учителя уроки
<!-- feature: monitoring · version: 1.0.1 -->
1. «Мониторинг» → период. «Ай» (месяц) считается с 1-го числа, «Жыл» (год) — с 1 января; до версии 1.0.1 в них попадал лишний последний день прошлого месяца или года.
2. По каждому учителю: «Пландалган» (запланировано), «Өткөрүлгөн» (проведено), «Калтырылган» (пропущено), «Кечиккен» (опоздания), «Көрсөткүч».
3. Нажмите на имя учителя — его уроки по дням: предмет, группа, статус, время прихода и окончания.

Урок считается пропущенным, если учитель не открыл его в журнале в своё время.
Если учителя заменили (см. «Заменить учителя»), уроки и пропуски до замены остаются у прежнего учителя, после — у нового.

## Отметить пропуск по уважительной причине
<!-- feature: excuses · version: 1.0.0 -->

1. «Себептүү катышпоо» (Пропуски по уважительной причине) → «Кошуу» (Добавить).
2. Студент, «Кайсы күндөн» и «Кайсы күнгө чейин» (с какого по какой день), «Себеби» (причина) → «Сактоо». Появится «Кошулду» (Добавлено).

## Настройка медресе — по порядку
Справочники заполняются один раз в начале года, дальше только меняются. Порядок важен: каждый следующий шаг выбирает из предыдущих.
Везде одинаково: «Кошуу» (Добавить) → поля со звёздочкой обязательны → «Сактоо» (Сохранить). Переспрашивать приложение не будет: появится «Кошулду» (Добавлено) или, при изменении, «Сакталды» (Сохранено).
В таблице карандаш — изменить, корзина — удалить: в вопросе «Бул жазууну өчүрөсүзбү?» (Удалить эту запись?) нажмите «Өчүрүү» (Удалить).
Удалить нельзя, пока на запись что-то ссылается — приложение скажет, что именно.
Если не получается: незаполненное обязательное поле подсвечивается красным с надписью «Бул талааны толтуруу милдеттүү» (Обязательное поле) — заполните его и снова нажмите «Сактоо». Остальные ошибки тоже пишутся по-кыргызски или по-русски, с названием поля.

### 8. Назначения
<!-- feature: assignments · version: 1.0.0 -->
«Дайындоолор»: учитель + предмет + группа + семестр + тип часов. Без назначения урок нельзя поставить в расписание.
В новом назначении «Семестр» уже выбран: активный семестр или тот, что стоит в «Семестр боюнча чыпка» (Фильтр по семестру).
Исправить назначение, не удаляя его: «Өзгөртүү» (Изменить) — на телефоне кнопка в карточке, на компьютере карандаш в строке → поправьте → «Сактоо».
- Предмет и «Саат түрү» (тип часов) можно менять всегда.
- Группу и семестр — только пока назначение не стоит в расписании. Иначе приложение напишет «Бул дайындоо жадыбалда турат — топту же семестрди алмаштыруу үчүн адегенде аны жадыбалдан алып салыңыз»: сначала уберите уроки из «Сабак жадыбалы».
- Учителя — см. следующий раздел.

### 8а. Заменить учителя
<!-- feature: teacher-replace · version: 1.0.0 -->
Когда нужно: учитель уходит или долго болеет, и его уроки в расписании должен вести другой.
1. Откройте «Дайындоолор» (Назначения).
2. Найдите назначение: поиск или «Семестр боюнча чыпка» (Фильтр по семестру).
3. Нажмите «Өзгөртүү» (Изменить) — на компьютере это карандаш в строке.
4. В поле «Мугалим» (Преподаватель) выберите нового учителя.
5. Нажмите «Сактоо» (Сохранить).
6. Если назначение стоит в расписании, приложение спросит: «Мугалим бардык келечектеги сабактарда алмашат. Өзгөртүүлөрдү сактайсызбы?» (Преподаватель будет заменён во всех будущих уроках. Сохранить изменения?). Нажмите «Ооба» (Да). «Жокко чыгаруу» (Отмена) — ничего не изменится.
7. Появится «Сакталды» (Сохранено).

Что будет:
- С сегодняшнего дня все уроки этого назначения в расписании — у нового учителя: он видит их в «Сабак жадыбалы» и ведёт журнал. У прежнего они пропадают.
- Уже проведённые уроки, их журнал и «Мониторинг» за прошлые дни остаются за прежним учителем. Приложение запоминает, кто и с какого дня вёл назначение, поэтому старые пропуски не переходят на нового учителя.
- Отдельного экрана «история замен» нет: кто вёл урок в прошлом, видно в «Мониторинг» → имя учителя.

Если не получается:
- «Жаңы мугалим бул убакта бош эмес: Дүй 2-сабак, …» (Новый преподаватель в это время занят) — у нового учителя в эти дни и пары уже есть уроки. Ничего не изменилось: выберите другого учителя или сначала перенесите его уроки.
- «Жаңы мугалим ушул кафедрадан болушу керек» (Новый преподаватель должен быть с той же кафедры) — заменить можно только учителем той же кафедры. Заведующий кафедрой видит в списке только своих учителей.

### 9. Расписание
<!-- feature: schedule-edit · version: 1.0.0 -->
«Сабак жадыбалы»: строки — пары, столбцы — дни. «+ кошуу» в свободной ячейке → назначение и аудитория → «Кошуу». Урок сразу появится в сетке, без вопроса.
Если учитель, группа или аудитория в это время заняты — приложение не даст поставить и объяснит почему.
Нажмите на урок:
- «Жылдыруу» (Перенести) → день, пара, аудитория → «Жылдырууну сактоо» → «Ооба». Урок переезжает во всех неделях, поэтому приложение переспрашивает.
- «Өчүрүү» (Удалить) → в вопросе снова «Өчүрүү». Если по уроку уже есть отметки, приложение предупредит ещё раз — кнопка «Баары бир өчүрүү» (Всё равно удалить) стирает и отметки.
